# 使うセンサ・知っておくべき FA センサ一覧

ソフトウェアエンジニアは「カメラ（AI）ですべてを解決しよう」としがちですが、工場自動化（FA）では **安価で壊れにくい産業用センサを組み合わせることで、システム全体の信頼性を劇的に上げられます。**

---

## 1. Task 1 で実際に使うセンサ（必須・準必須）

| センサ | 用途（Task 1） | 選定・運用のポイント |
| --- | --- | --- |
| **RGB-D カメラ** | 山積みボトルの位置・向き・高さ Z の認識 | 基本は固定（Eye-to-Hand）。色付き透明ボトルでの Depth 欠損は事前検証必須 |
| **真空圧力スイッチ** | **吸着パッドがボトルを吸えたか／途中で落としていないか**の判定 | **必須**。コントローラの 24V DI に繋ぎ、空振り時のリトライや落下検知に使う |
| **光電センサ** | ・コンベアの置き場所が空いているか検知<br/>・受け皿のボトル切れ／満杯（山が高すぎないか）検知 | カメラより圧倒的に高速・確実。**※色付き透明ボトルがある場合は「透明体検出対応（偏光回帰反射型等）」を選ぶこと** |

## 2. 今後の FA（Task 2 以降含む）で知っておくべき定番センサ

| センサ種類 | 原理・特徴 | よく使われる場面 |
| --- | --- | --- |
| **安全エリアスキャナ / ライトカーテン** | レーザーや赤外線カーテンで人の侵入を検知 | 協働ロボットの近くに人が入ったら減速・安全停止させる（**Safety I/O に直結**） |
| **近接センサ（誘導型 / 静電容量型）** | 非接触で金属（誘導型）や樹脂・液体（静電容量型）を検知 | 治具がセットされたか、安全扉が閉まったか（ホコリ・油に非常に強い） |
| **オートスイッチ（磁気センサ）** | エア機構・シリンダのピストン位置を検知 | グリッパやゲート機構が「開いた／閉じた」の確認 |
| **力覚センサ（6軸 F/T センサ）** | 手首に加わる 3軸の力と 3軸のモーメントを計測 | 部品の嵌め合い、押し付け、差し込み作業（協働ロボットは内蔵トルクセンサで簡易代用可） |
| **ロータリーエンコーダ** | 回転量・移動量をパルス信号で計測 | **動いているコンベアを止めずにロボットが追従して置く（コンベアトラッキング）**ときに必須 |
| **超音波 / レーザー距離センサ** | 対象物までの距離を 1点（または帯域）で計測 | 透明ボトルの通過検知（超音波は透明でも関係なく反射する）、ホッパー残量検知 |

## 3. 光電センサの仕組みと ToF との使い分け

### 光電センサの3タイプ
- **透過型**（投光器＋受光器が向かい合わせ）：一番確実だが両側に配線が必要。
- **回帰反射型**（本体＋反対側に反射板）：片側配線で済む。**「透明体検出用」モデルなら色付き透明ボトルも素通りせず確実に検知できるため Task 1 に最適。**
- **拡散反射型**（本体のみで反射光を見る）：反射板不要だが、ワークの色や透明度の影響を受けやすい。

### なぜ「ボトル有無検知」に ToF ではなく光電センサを使うのか
- ToF（距離）センサは対象物からの反射光で距離を測るため、**透明・色付き透明ボトルだと光が突き抜けて後ろの壁を測ってしまう（素通り）**リスクや、円筒曲面で光が逃げるリスクがある。
- **ToF（や超音波）が活きるのは**「コンベア上の1本有無」ではなく、**「ホッパーにボトルが何cm積み上がっているか（残量・満杯高さ）」**を上から測りたい場面。

## 4. センサの接続方法と電源電圧（マイコン不要・ほぼすべて DC24V）

### ① 何に繋ぐのか？（マイコンや USB は不要）
- 産業用センサは **ロボットコントローラの 24V DI 端子へ直接ネジ止め接続** する（工場現場でノイズに弱い自作マイコンや USB シリアルは挟まない）。
- 一般的な3線式センサの配線：
  - **茶色（+24V）** → DC24V 電源へ
  - **青色（0V）** → DC24V 電源の 0V へ
  - **黒色（OUT）** → **ロボットコントローラの `DI` 端子**へ（PC からは `robot.get_di()` で取得）
- ※I/O 点数がコントローラ標準（8〜16点）で足りなくなった場合は、マイコンではなく **Modbus TCP 対応の産業用リモート I/O ユニット** を LAN スイッチに1台足す。

### ② 電圧は本当にすべて DC24V なのか？
- **はい、FA 用センサ・機器（光電・近接・真空スイッチ・電磁弁・パトランプ・押しボタン）はほぼ 100% が DC24V（DC12〜24V / 10〜30V）標準**です。制御盤に DC24V 電源を1個入れればすべてそのまま動きます。
- **例外**：カメラ（USB 5V / PoE 48V）、古い既存設備の AC100V 信号（リレーを1個挟んで無電圧接点に変換して受ける）、アナログ距離センサの出力信号（`0〜10V` / `4〜20mA`、ただし電源は DC24V）。

## 5. センサ選定時の共通チェックポイント
1. **出力極性（NPN / PNP）**：ロボットコントローラの DI 仕様と必ず一致させる（[`05_fa_io_and_plc.md`](../03_robotics_handbook/05_fa_io_and_plc.md)）。
2. **応答速度とチャタリング**：高速に通過するワークには応答速度（数ms以下）と、ソフト側でのチャタリング除去（連続 N ms 検知で確定）を入れる。
3. **「カメラでやるか、光電センサでやるか」の切り分け**：
   - 「色や向きを識別する」→ **カメラ（YOLO）**
   - 「物がここにあるか・ないか（0/1）」→ **光電センサ / 近接センサ**（照明変化に強く、AIの誤検出ゼロ）
