# エンドエフェクタ選定メモ（Task 1：真空吸引 vs グリッパ）

Task 1（バラ積み状態のボトルを拾ってコンベアへ置く工程）における、**真空吸引（吸着パッド）** と **ハンド（グリッパ）** の比較・検討メモです。

## 1. 結論
**ボトルが軽量（空ボトルや小型）で吸着できる面があるなら、バラ積みでは「真空吸引（吸着）」が第一候補として非常に相性が良いです。**

## 2. 真空吸引 vs グリッパ 比較

| 観点 | 真空吸引（吸着パッド） | ハンド（2指/3指グリッパ） |
| --- | --- | --- |
| **密集・バラ積みへの強さ** | **◎** 周囲のボトルと干渉せず、片面からアプローチできる | △ 指を開く隙間が必要で、密集時に隣のボトルに当たりやすい |
| **ソフト・ビジョン連携の難易度** | **◎** 面の中心＋法線方向へ当てるだけでよい | △ 指の開き幅・挟み込み方向・衝突回避の計算が複雑 |
| **コスト・重量** | **◎** 安価・軽量（特に工場エア利用時） | △ 電動グリッパは高価（20〜50万円帯）で重い |
| **重いワーク・姿勢保持** | △ 重いボトルや横持ち時にズレ・剥がれリスクあり | **◎** 物理的に挟むため把持力・姿勢保持が強い |
| **凹凸・曲面・ラベル** | △ 曲面対応パッド（蛇腹等）が必要。大きな凹凸やリブに弱い | **◎** 多少凹凸があっても挟める |

## 3. ボトルを真空吸引する際のチェックポイント

1. **ボトルの重さと中身（空か中身入りか）**
   - 空のPET/樹脂ボトルであれば吸着1点で十分安定しやすい。
   - 中身入りの重いボトル（500g〜1kg超）やガラス瓶の場合は、パッド面積を大きくする／複数パッドにする／**重心がズレて剥がれないか**実機テストが必須。
2. **ボトル形状とパッド選定（曲面・リブ対策）**
   - 円筒の側面は曲面のため、平パッドではなく **ベローズ（蛇腹）型・柔らかいリップ形状・楕円形** など曲面追従性の高いパッドを選ぶ。
   - 胴体に深い溝やエンボス、剥がれやすいラベルがあるとエア漏れの原因になる。
3. **「どこを吸って、どう置くか」の干渉チェック**
   - 横倒しのボトルの胴体側面を吸って「立てて」コンベアに置く場合、コンベア面とアーム・パッドが干渉しないか配置を確認する。
   - キャップ上部は小さく凹凸もあるため、通常は**胴体側面（または底面）**を吸う方が安定する。
4. **工場の圧縮エアの有無**
   - **エア配管あり**：真空エジェクタ（数千円〜数万円）で強力かつ安価に組める。
   - **エア配管なし**：電動真空グリッパ（数十万円クラス）または小型真空ポンプの搭載が必要になり、コスト・重量が増える。
5. **吸着確認センサ（真空スイッチ）の必須化**
   - 「吸ったつもりで落としていた」を防ぐため、真空圧を監視するデジタル入力を必ずアーム／PLC側に取り込み、吸着失敗時は自動リトライする。
