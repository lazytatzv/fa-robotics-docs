# エンドエフェクタ選定メモ（Task 1：真空吸引 vs グリッパ）

Task 1（バラ積み状態のボトルを拾ってコンベアへ置く工程）における、**真空吸引（吸着パッド）** と **ハンド（グリッパ）** の比較・検討メモです。

## 1. 結論
**対象が空ボトル（軽量）であり、かつボトルによって若干形状が異なる可能性があるため、「真空吸引（吸着）」が最適解になる可能性が非常に高いです。**

- **空ボトルとの相性**：軽量のため1点吸着で安定しやすく、ロボットの可搬質量（3〜5kgクラス）にも余裕が出る。逆にハンド（グリッパ）だと薄肉ボトルを押し潰すリスクがある。
- **形状バラつきへの耐性**：専用メカ（整列機）や専用爪のグリッパと違い、柔らかい蛇腹（ベローズ）型の吸着パッドであれば、曲率やサイズの多少の違いをそのまま吸収できる。

## 2. 真空吸引 vs グリッパ 比較

| 観点 | 真空吸引（吸着パッド） | ハンド（2指/3指グリッパ） |
| --- | --- | --- |
| **密集・バラ積みへの強さ** | **◎** 周囲のボトルと干渉せず、片面からアプローチできる | △ 指を開く隙間が必要で、密集時に隣のボトルに当たりやすい |
| **ソフト・ビジョン連携の難易度** | **◎** 面の中心＋法線方向へ当てるだけでよい | △ 指の開き幅・挟み込み方向・衝突回避の計算が複雑 |
| **コスト・重量** | **◎** 安価・軽量（特に工場エア利用時） | △ 電動グリッパは高価（20〜50万円帯）で重い |
| **重いワーク・姿勢保持** | △ 重いボトルや横持ち時にズレ・剥がれリスクあり | **◎** 物理的に挟むため把持力・姿勢保持が強い |
| **凹凸・曲面・ラベル** | △ 曲面対応パッド（蛇腹等）が必要。大きな凹凸やリブに弱い | **◎** 多少凹凸があっても挟める |

## 3. ボトルを真空吸引する際のチェックポイント

1. **ボトルの重さと中身（空か中身入りか）**
   - 空のPET/樹脂ボトルであれば吸着1点で十分安定しやすい。
   - 中身入りの重いボトル（500g〜1kg超）やガラス瓶の場合は、パッド面積を大きくする／複数パッドにする／**重心がズレて剥がれないか**実機テストが必須。
2. **ボトル形状とパッド選定（曲面・リブ対策）**
   - 円筒の側面は曲面のため、平パッドではなく **ベローズ（蛇腹）型・柔らかいリップ形状・楕円形** など曲面追従性の高いパッドを選ぶ。
   - 胴体に深い溝やエンボス、剥がれやすいラベルがあるとエア漏れの原因になる。
3. **「どこを吸って、どう置くか」の干渉チェック**
   - 横倒しのボトルの胴体側面を吸って「立てて」コンベアに置く場合、コンベア面とアーム・パッドが干渉しないか配置を確認する。
   - キャップ上部は小さく凹凸もあるため、通常は**胴体側面（または底面）**を吸う方が安定する。
4. **工場の圧縮エアの有無（エア源・減圧・エジェクタの仕組み）**
   - **① 工場のエア配管から分岐（本命・一番安い）**：ほとんどの工場には柱や天井に圧縮空気（0.5〜0.7MPa）のカプラが来ている。
     - **減圧と水抜き**：配管の途中に **フィルタレギュレータ（減圧弁）** を1個挟み、ツマミを回して `0.4〜0.5MPa` 程度に減圧しつつゴミ・水滴（ドレン）を抜く。
     - **真空の発生（エジェクタ）**：減圧したエアを **真空エジェクタ** に流すと、ベンチュリ効果（霧吹きと同じ原理）で `-80kPa` 程度の負圧が発生する。可動部品がなく超軽量・高速・安価。
     - **オールインワン型ユニット**：実務では「エジェクタ＋吸着用電磁弁＋破壊ブロー電磁弁（スピコン付）＋真空圧力スイッチ＋サイレンサ」が1ブロックに一体化したユニット（例：SMC `ZK2` 等）を使うと配線・配管が最小になる。
   - **② 小型オイルレスコンプレッサーを置く（PoC・配管なし現場）**：手元にエアが無い場合は、架台下に数万円の**静音・オイルレスコンプレッサー**を置く（※給油式は油ミストでボトルを汚すためNG）。
   - **③ 電動真空グリッパ（エア完全不要）**：モーター（真空ポンプ）内蔵型を使う。配管不要だが、価格が高く（十数万〜40万円帯）手先も重くなるため、エア配管があるならエジェクタ式が圧倒的に有利。
5. **吸着確認センサ（真空スイッチ）の必須化**
   - 「吸ったつもりで落としていた」を防ぐため、真空圧を監視するデジタル入力を必ずアーム／PLC側に取り込み、吸着失敗時は自動リトライする。

## 4. 空ボトルを「倒さず・張り付かせず」離すためのリリース設計

空ボトルは軽いため、**「ただ吸着用電磁弁を OFF にするだけ」** だと、チューブ内の残圧やゴムの張り付きでボトルがパッドにくっついたままになり、アームが動いた瞬間に落ちて倒れるトラブルが起きやすいです。

### 現場で確実に離すための4つの対策

1. **微少な「真空破壊ブロー」＋ スピコン（絞り弁）**
   - 吸着 OFF と同時に、破壊ブロー用電磁弁を **50〜150ms だけ ON** にしてチューブ内の負圧を強制的に大気圧へ戻す。
   - **重要**：空ボトルは軽いため、そのままの工場エア圧で吹くと**ボトルが吹き飛んで倒れる**。破壊ブロー側の配管に必ず**スピードコントローラ（絞り弁）**を入れ、「フッと優しく離れる」レベルまで風量を絞る。
2. **底面がコンベアに「触れるギリギリ（0〜2mm）」まで降ろしてから離す**
   - 少し上から落とすと空ボトルは跳ねて倒れるため、底面がコンベアに接地する直前〜軽く触れる高さまで `MoveL` で降ろしてからリリースする。
3. **リリース後の「逃げ方向」を工夫する**
   - 側面を吸って立てて置いた場合、すぐ真上に引き抜くとパッドのゴムがボトル側面に引っかかって持ち上げ・転倒の原因になる。
   - 破壊ブロー後、**50〜100ms 待機**してから、まずは**吸着面から垂直に離れる方向（横へ 20〜30mm `MoveL`）**へ抜くと倒れにくい。
4. **コンベア側の物理ガイド（そもそも立てる必要があるかも要確認）**
   - 立てて置く仕様の場合、コンベア両脇に**ガイドレール**があれば多少傾いても自立する。
   - そもそも後工程で「寝かせて置いてもOK」なら、寝かせて置く方が転倒リスクはゼロになる。

## 5. ロボット手先に「ポン付け」できる既製アタッチメントはあるか？

**はい、エジェクタ・電磁弁・真空スイッチ・パッドまで全部入った「協働ロボット用オールインワン真空グリッパ」が市販されています。**
ソフト系チームがゼロから空圧マニホールドを組むより、まずは以下の既製アタッチメントを検討するのが圧倒的に早くて確実です。

| 方式 | 代表的な製品例 | 特徴・メリット |
| --- | --- | --- |
| **エア駆動・ポン付け一体型**<br/>（工場エアあり向け） | ・**SMC `ZXP7` シリーズ**<br/>・**Piab `piCOBOT`**<br/>・**Schmalz `ECB` / `FXCB`** | ・協働ロボットの標準フランジ（ISO 9409-1-50-4-M6）にボルト4本で直付け可能<br/>・エジェクタ・電磁弁（吸着/破壊）・圧力スイッチが内蔵済み<br/>・ロボット手首の **ツールI/Oコネクタ（M8 8ピン等）** に直接繋げる機種が多く配線が最小限<br/>・電動式より軽量・高速・安価（数万〜十数万円クラスから） |
| **電動（ポンプ内蔵）ポン付け型**<br/>（エア配管なし向け） | ・**OnRobot `VGC10` / `VG10`**<br/>・**Robotiq `EPick`**<br/>・**SMC `ZXPE5`** | ・圧縮エア配管が一切不要（電気ケーブル1本で動作）<br/>・ただしエア式に比べて価格が高く（数十万円帯）、手先重量も重くなる |

> **選定のコツ**：ロボット選定時に「手首の先端（ツールフランジ）に **DC24V ＋ DI/DO が出ているコネクタ** があるか」「フランジ規格が **ISO 9409-1-50-4-M6** か」を確認しておくと、こうした既製アタッチメントをそのまま流用できます。
