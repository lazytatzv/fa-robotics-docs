# 協働ロボット選定メモ（本体100万円前後帯）

## 1. 予算構造の前提（ソフトチームへの共有ポイント）
「ロボット本体が100万円前後」であっても、**工場で稼働するシステム全体の費用は本体価格の2〜3倍になるのが一般的**です。

- **ロボット本体**：〜100万円前後
- **エンドエフェクタ**：電動グリッパ（20〜50万円）または吸着・エア駆動系（コンプレッサ・電磁弁含む）
- **架台・治具**：アルミフレーム架台、ワーク位置決め治具（数万〜数十万円）
- **センサー・カメラ**：2D/3Dカメラ、光電センサ等
- **安全機器・制御盤**：非常停止スイッチ、安全リレー、24V電源、必要に応じて安全エリアスキャナ・安全柵

## 2. 100万円前後帯の協働ロボットで必ず確認すべき観点

大手（UR / FANUC CRX / Techman 等）は本体だけで300〜500万円以上することが多いため、100万円前後帯では新興・中国系・小型協働アーム（例：Dobot、Fairino、UFACTORY xArm、Elephant Robotics 等）が主な候補になります。以下の4点は工場導入時にトラブルになりやすいため事前確認が必須です。

| 確認項目 | 確認内容 | なぜ重要か |
| --- | --- | --- |
| **安全規格・安全I/O** | ISO 10218 / ISO/TS 15066 準拠か、ハードウェアの安全入力（STO等）があるか | 安価な機体は「衝突検知はあるが安全認証なし」の場合があり、工場側の安全基準次第で結局**安全柵が必須**になる |
| **環境耐性（IP等級）・連続稼働** | IP54/IP65等の防塵・防滴性能、連続稼働の想定 | 工場の油ミスト・粉塵・長時間稼働に耐えられるか |
| **ソフト制御I/F** | ROS 2公式パッケージ、Python/C++ SDK、Modbus/TCP 等の有無 | ソフトチームが作り込みやすいか、リアルタイム制御（サーボ周期）ができるか |
| **国内サポート・保守** | 国内代理店の有無、故障時の修理リードタイム・代替機対応 | 工場ラインが止まったときに数週間〜数ヶ月止まらないか |
