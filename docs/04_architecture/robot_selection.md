# 協働ロボット選定メモ（本体100万円前後帯）

## 1. 予算構造の前提（ソフトチームへの共有ポイント）
「ロボット本体が100万円前後」であっても、**工場で稼働するシステム全体の費用は本体価格の2〜3倍になるのが一般的**です。

- **ロボット本体**：〜100万円前後
- **エンドエフェクタ**：電動グリッパ（20〜50万円）または吸着・エア駆動系（コンプレッサ・電磁弁含む）
- **架台・治具**：アルミフレーム架台、ワーク位置決め治具（数万〜数十万円）
- **センサー・カメラ**：2D/3Dカメラ、光電センサ等
- **安全機器・制御盤**：非常停止スイッチ、安全リレー、24V電源、必要に応じて安全エリアスキャナ・安全柵

## 2. 100万円前後帯の協働ロボットで必ず確認すべき観点

大手（UR / FANUC CRX / Techman 等）は本体だけで300〜500万円以上することが多いため、100万円前後帯では新興・中国系・小型協働アーム（例：Dobot、Fairino、UFACTORY xArm、Elephant Robotics 等）が主な候補になります。以下の4点は工場導入時にトラブルになりやすいため事前確認が必須です。

| 確認項目 | 確認内容 | なぜ重要か |
| --- | --- | --- |
| **安全規格・安全I/O** | ISO 10218 / ISO/TS 15066 準拠か、ハードウェアの安全入力（STO等）があるか | 安価な機体は「衝突検知はあるが安全認証なし」の場合があり、工場側の安全基準次第で結局**安全柵が必須**になる |
| **環境耐性（IP等級）・連続稼働** | IP54/IP65等の防塵・防滴性能、連続稼働の想定 | 工場の油ミスト・粉塵・長時間稼働に耐えられるか |
| **ソフト制御I/F** | ROS 2公式パッケージ、Python/C++ SDK、Modbus/TCP 等の有無 | ソフトチームが作り込みやすいか、リアルタイム制御（サーボ周期）ができるか |
| **国内サポート・保守** | 国内代理店の有無、故障時の修理リードタイム・代替機対応 | 工場ラインが止まったときに数週間〜数ヶ月止まらないか |

## 3. 軸数の選定方針（6軸 vs 4軸 vs 7軸）

**方針：Task 1（落下ボトルのピッキング＆整列）を前提とする場合、6軸協働ロボットが最も妥当。**

| 軸数 | 特徴 | Task 1 への適合性 |
| --- | --- | --- |
| **4軸（SCARA等）** | 高速・安価だが、手先を常に真下向きにしか向けられない（X, Y, Z, Rz） | △ ボトルが横倒し・斜めの状態から姿勢を起こして置く作業ができない（※前段のメカで完全に整列できるなら有力） |
| **6軸（標準協働）** | 3次元位置（X,Y,Z）＋任意姿勢（R,P,Y）をとれる。市場の標準で情報・SDKが豊富 | **◎ 最適**。横倒し・傾いたボトルを掴み、向きを揃えてコンベアへ置ける。初心者チームも扱いやすい |
| **7軸（冗長軸）** | 肘の逃げを作れるため障害物回避に強いが、IKに冗長性があり挙動が複雑・機種が限られる | ○ 狭小スペースなら有効だが、100万円帯では選択肢が少なくデバッグ難易度も上がる |

### 6軸採用時の注意点（教育・設計ポイント）
- **特異点（Singularity）**：手首軸が一直線になる姿勢などで動作エラーや速度低下が起きるため、直線補間（LIN）と関節補間（PTP）の使い分けや配置設計が重要。
- **リーチと手首の干渉**：ボトルの「横」から掴みに行く姿勢をとると、真上から掴むよりアームの実効リーチが短くなり、周囲の壁・ホッパーに手首が干渉しやすくなる。

## 4. 候補メーカー・機種比較（100万円前後帯中心）

> **前提**：世界定番の大手協働ロボット（**Universal Robots / FANUC CRX / 安川 HC / DENSO / Techman** 等）は本体だけで **300万〜500万円以上** するため、**100万円前後帯** では以下の新興・中国系メーカーが主な現実解になります。

| メーカー / シリーズ | 想定価格帯（目安） | ソフト連携（SDK / ROS 2） | 特徴・工場導入時のチェック点 |
| --- | --- | --- | --- |
| **Dobot** (`CR3 / CR5`, `Nova`) | 100万円前後〜100万円台前半 | Python / C++ SDK、ROS 2、Modbus TCP | 国内代理店・導入事例が比較的多い。工場用途のコントローラ・24V I/O が一通り揃っている |
| **Fairino** (`FR3 / FR5`) | 100万円前後 | Python / C++ SDK、ROS 2、Web UI | コスパが高く最近日本の検証・FA導入で増加中。国内代理店の保守体制を事前確認する |
| **UFACTORY** (`xArm 6` / `Lite 6`) | 100万円前後〜 | Python / C++ SDK、ROS 2 の完成度が非常に高い | ソフト系チームに最も扱いやすい。工場導入時は **IP等級・安全認証・安全柵の要否** を要確認 |
| **JAKA** (`Zu 3 / Zu 5`) | 100万円台後半〜 | Python / C++ SDK、ROS 2 | 日本法人があり工場実績・品質面で安心感がある（予算が少し上がる場合あり） |

### 代理店に見積もり・デモ依頼するときの必須確認事項
1. **100万円前後に「コントローラ・接続ケーブル・24V I/O端子」がすべて含まれているか**（別売りオプションに注意）
2. **ISO 10218 / ISO/TS 15066 等の安全認証**を取得しているか（未取得・条件付きの場合は安全柵やエリアスキャナを併設）
3. **故障時の国内修理リードタイム・代替機貸出の有無**
4. **デモ機・ショールームで実物ボトル（＋カメラ）のテストができるか**

## 5. FA（工場導入）目線のおすすめランキング

### ① 予算 100万円前後〜100万円台帯（今回の条件）
| 順位 | メーカー / 機種 | FA 目線での評価理由 |
| --- | --- | --- |
| **1位** | **Dobot `CR` シリーズ** (`CR3 / CR5`) | 国内代理店網・工場実績・コントローラ（24V I/O）・SDK/ROS 2 の**総合バランスが最も安定** |
| **2位** | **JAKA `Zu` シリーズ** (`Zu 3 / Zu 5`) | **日本法人があり工場品質・信頼性が高い**（※予算が100万円台後半〜に上がる場合は最有力） |
| **3位** | **Fairino `FR` シリーズ** (`FR3 / FR5`) | **コスパ最強**（100万円前後で可搬・リーチが優秀）。代理店の保守対応を確認できれば強い |
| **4位** | **UFACTORY `xArm 6` / `Lite 6`** | **SDK / ROS 2 の開発しやすさは1位**。ただし工場の安全認証・IP等級次第で安全柵/スキャナ併用が前提 |

### ② （参考）予算を 300〜500万円帯まで上げられる場合の FA 王道
顧客が「止まらない耐久性・大手メーカーの安全認証」を最優先する場合はこちらに切り替える：
1. **Universal Robots (`UR3e / UR5e`)** — 協働ロボットの世界標準。SMC `ZXP7` やカメラ、ROS 2 のエコシステムが最強
2. **FANUC `CRX` シリーズ (`CRX-5iA / 10iA`)** — 日本工場での耐久性・保守網が最強（ただしソフト屋には周辺設定がやや硬め）
3. **DENSO `COBOTTA PRO` / 安川 `HC` / Techman `TM`** — 国内サポートや標準ビジョン内蔵など用途に応じて有力
