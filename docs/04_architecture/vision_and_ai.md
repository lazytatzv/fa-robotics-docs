# ビジョン・AI認識方針（Task 1：ボトル認識）

## 1. カメラは必要か？
**2階からランダムに落ちてくる状態から拾う場合、カメラは必須です。**
（機械的なガイドやパーツフィーダで完全に1列・同姿勢に整列できる場合は光電センサのみで済みますが、ボトル形状に若干のバラつきがある場合はカメラで位置・姿勢を認識する方が柔軟に対応できます。）

## 2. AI（YOLO等）は使うべきか？

**結論：使う価値は高いですが、「普通の物体検出（水平矩形）」だけではロボットは掴めません。**

ソフトウェアエンジニアが最初につまずきやすい点として、通常の YOLO（`x, y, w, h` のバウンディングボックス）では **「ボトルが何度傾いているか」「口（トップ）がどっちを向いているか」** が分からないため、コンベアに正しい向きで置けません。

### おすすめの認識アプローチ

| 手法 | 取れる情報 | メリット・向いているケース |
| --- | --- | --- |
| **YOLO-pose（キーポイント検出）** | ボトルの「口」と「底」の2点 | **◎ 最有力**。中心座標・傾き・上下の向きが一発で決まり、吸着点と置く向きを同時に計算できる |
| **YOLO-seg（インスタンスセグメンテーション）** | ボトル1本ごとの領域マスク | 重なりがある山積みでも「一番上に乗っているボトル」を抽出しやすい（マスクの主軸から傾きを算出） |
| **YOLO-OBB（回転矩形）** | 傾き付き矩形 | 傾きは取れるが、上下（口と底）の判別には別クラス分けや追加判定が必要 |
| **古典的画像処理（OpenCV等）** | 輪郭・重心・主軸 | 背景と色の差が大きく重なりがない場合に超高速。ただし透明ボトルや重なりには弱い |

## 3. 2Dカメラ vs 3Dカメラ（RGB-D）の選び方

- **山積み（高さがバラバラ）のまま拾う場合**：
  - 高さが分からないとアームが衝突するため **3D（デプス）カメラ** が必要。
  - ただし **透明・光沢ボトルはデプス値が欠損しやすい** ため、実物での事前検証（Step 2 PoC）が必須。
- **受け皿・振動フィーダ等で「1層（重なりなし）」に広げられる場合**：
  - 高さがほぼ一定になるため **2Dカメラ（普通のRGBカメラ）＋ AI（YOLO-pose / seg）** だけで成立する。
  - 安価・高速で、透明ボトルでも照明（バックライトや斜光）の工夫で認識しやすい。

## 4. カメラ設置とキャリブレーションの注意点
- **設置方式**：
  - **Eye-to-Hand（固定カメラ）**：作業エリアの上方に固定。1回の撮影で全体を見渡せ、ロボット動作中も次のボトルを先読み計算できるため**タクト短縮に有利**。
  - **Eye-in-Hand（手先カメラ）**：アーム先端に搭載。近づいて高精度に見られるが、毎回撮影位置へ移動する時間がかかる。
- **座標変換**：
  - カメラのピクセル座標 `(u, v)` をロボットのベース座標 `(X, Y, Z)` に変換するため、**キャリブレーション（平面ホモグラフィ／Hand-Eyeキャリブレーション）** が必須になる。
