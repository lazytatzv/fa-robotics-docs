# プロの機器・センサ選定プレイブック（失敗しない見極め基準）

素人がカタログの「価格と最大スペック」だけを見て選んで失敗しやすいポイントを回避し、**プロの FA エンジニア（ロボット SIer）が実務で必ず確認している選定基準**をすべてまとめました。

---

## 1. プロが選ぶ「正しい順番」（逆算思考）

- ❌ **素人の順番**：まず話題のロボット（100万円）を買う → 後から「リーチが足りない」「手先が重い」「安全認証がない」と気づく。
- ⭕ **プロの順番**：
  1. **ワーク・工程**から **「エンドエフェクタ（吸着パッド・エジェクタ）」** を決める
  2. **必要な姿勢・作業範囲・タクト・総重量**から **「ロボット本体」** を決める
  3. **工場環境（粉塵・水・油・外光・透明度）**から **「IP等級・カメラ・センサ」** を決める
  4. **保守性・納期・国内サポート**で **メーカーを絞り込む**

---

## 2. コンポーネント別・プロの裏チェック基準

### ① 協働ロボット本体
- **実効リーチ**：カタログ最大リーチの **70〜80%** の範囲に作業エリアが収まるか（手首を横に向けるとさらに短くなる）。
- **可搬質量とモーメント**：ワーク＋アタッチメント＋ケーブル重さに加え、重心オフセットと高速加減速時の慣性モーメントに余裕があるか。
- **安全認証と Safety I/O**：ISO 10218 / ISO/TS 15066 準拠か、非常停止・安全機器用のハード安全入力（STO）があるか。
- **フランジ＆ツール I/O**：先端が世界標準 **ISO 9409-1-50-4-M6** か、手首に 24V ツール I/O コネクタがあるか。
- **電源・I/O 極性**：`AC100-240V` 対応か（AC220V専用に注意）、DI/DO が PNP/NPN どちら対応か。
- **国内サポートと代替機**：故障時の修理リードタイム、国内代理店の技術サポート、部品供給期間（5〜10年）。

### ② FA センサ（光電・真空スイッチ・近接等）
- **FA 規格品一択**：秋月電子・Amazon のホビー用は禁止。オムロン・キーエンス・SMC・パナソニック・SICK 等を選ぶ。
- **IP保護等級**：乾燥工場なら `IP54` 以上、水洗い・油ミスト環境なら **`IP65`〜`IP67`**（光電センサは基本 `IP67`）。※コントローラや PC は `IP20` 程度なので必ず制御盤に入れる。
- **コネクタ仕様（M8 / M12）**：配線直出しではなく**コネクタ中継タイプ**を選ぶと、現場でセンサが壊れたときにドライバー不要で数分で交換できる。
- **出力仕様**：極性（**NPN / PNP**）と動作モード（**入光ON / 遮光ON 切替可**）を確認する。
- **透明・色付き透明ワーク**：必ず**透明体検出対応（偏光回帰反射型等）**または超音波センサを選ぶ。

### ③ カメラ・レンズ・照明
- **シャッター方式**：動くワークや振動環境では**グローバルシャッター**（ローリングシャッターは歪む）。
- **固定焦点レンズ（ロックネジ付き）**：フォーカスと絞りを固定ネジで締められる産業用レンズを選ぶ（振動でピントがズレない）。
- **接続と固定**：本番は **PoE / GigE** 推奨。USB を使うならネジ止めロック対応＋アクティブ延長。

### ④ 吸着パッド・空圧部品（SMC / CKD 等）
- **パッド材質の使い分け**：
  - **シリコンゴム**：ワークに跡（色移り）が付きにくい、耐熱性あり（空ボトル・食品/包装向け）
  - **ニトリルゴム（NBR）**：耐油性が高い（金属・油環境向け）
  - **ウレタンゴム**：耐摩耗性が高い（ザラザラした箱・ダンボール向け）
- **ワンタッチ継手とチューブ径の統一**：現場で使うチューブ径（例：Φ6）を統一し、パッドも工具なしで交換できる構造にする。

### ⑤ 制御PC・電源・盤内機器
- **産業用PC（IPC）**：同型番を 3〜5 年追加購入できる長期供給モデル、防塵/ファンレス、**BIOS 復電自動起動**対応、Intel NIC × 2系統。
- **DC24V 電源の容量余裕（ディレーティング）**：計算上の消費電力ピッタリではなく、**実負荷の 1.5〜2倍の定格容量**（稼働率 50〜70%）を選ぶ（熱劣化と電磁弁の突入電流対策）。
- **産業用スイッチングハブ**：DINレール取付・金属筐体・DC24V 駆動（ACアダプタ式の家庭用ハブは使わない）。

## 3. プロが見積もり・設計時に必ず確認する「運用・調達ルール」
1. **「今すぐ国内で買えるか・3年後も買えるか」**
   - ミスミ・モノタロウ・国内商社で型番が流通していて、納期が読める部品だけを採用する（海外通販で1〜2ヶ月待ちの部品を本番機に組み込まない）。
2. **「消耗品・予備品」を最初からセットで確保する**
   - 予備の吸着パッド、予備の光電センサ、予備ケーブル、PC用防塵フィルタは納品時に必ず予備として持っておく。
