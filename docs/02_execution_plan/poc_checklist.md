# Task 1 PoC（要素検証）チェックリスト

全体システムを買い揃えて作り込む前に、**失敗リスクの高い要素だけを最小コストで検証する**ためのチェックリストです。

## 1. 最優先 PoC 項目（Step 2）

| # | 検証項目 | 確認方法 | 合格基準の目安 |
| --- | --- | --- | --- |
| 1 | **色付き透明ボトルの Depth 取得** | 実物ボトル（不透明＋色付き透明）を机上に山積みし、RealSense / Orbbec 等で撮影 | 吸着面付近の Depth 欠損が許容範囲内、または RGB 補間で Z 推定できること |
| 2 | **空ボトルへの真空吸着安定性** | 候補の蛇腹パッド＋エジェクタ（またはポンプ）で、各形状の空ボトルを側面吸着して振り回す | 横持ち・90度回転させてもズレず、凹みや変形が起きないこと |
| 3 | **YOLO-pose / seg の認識精度** | 山積み状態のテスト画像（50〜100枚程度）で「口・底」または領域マスクを推論 | 一番上にあり吸着可能なボトルと向きを安定して判定できること |
| 4 | **サイクルタイム（タクト）試算** | 実機（またはレンタル／メーカーデモ機）で 1ピック＆プレースの所要時間を計測 | 工場が求める 1分あたりの本数（BPM）を満たせる見込みがあること |
| 5 | **Ubuntu Linux からの制御検証** | 候補ロボットの Python SDK / ROS 2 ドライバを Ubuntu PC から繋いで移動＋I/O テスト | 座標移動と DO（吸着）・DI（真空スイッチ）の読み書きが遅延なく動くこと |

## 2. FA のプロが PoC で真っ先にやる「3つの鉄則」

1. **「そもそもメカ・前段で問題を簡単にできないか」を最初に疑う**
   - 山積みのまま 3D 認識するより、受け皿に傾斜や振動板を入れて「1〜2層にほぐしてから拾う」方が圧倒的に安定する。
2. **「80点の AI 認識 ＋ 物理の逃げ（バネ・ガイド）」で 99.9% にする**
   - ソフトだけで 99.9% を目指さず、パッドのバネバッファ・コンベアのガイドレール・光電センサで物理的にズレを吸収する。
3. **購入前に実物ボトルで成立性を確認する（テストルームが無い場合の現実解）**
   - 大手（UR・FANUC・SMC・キーエンス等）は東京・大阪・名古屋にテストルームがあるが、**100万円帯のメーカーや地方では近くにテストルームがないのが現実**。
   - **代替策**：
     - **カメラと吸着の検証はロボット本体なしでできる**（RGB-D カメラで机上撮影 ＋ パッド/エジェクタを手で当てて吸えるかテスト）。
     - ロボット実機は代理店の **「短期デモ機レンタル（1〜2週間）」** を使うか、**「実物ボトルを代理店へ送ってテスト動画を撮ってもらう」** のが現実的。

## 4. 机上での「吸着単体テスト」何を買うか・どうやるか

ロボット実機を買う前に、まずは数千円〜2万円で手元の机で「空ボトルを吸えるか」をテストできます。

### 買うものリスト（2パターン）

#### パターンA：最安・最短で「吸えるか」だけ試す（合計 5,000〜8,000円目安）
- **FA 用 蛇腹（ベローズ）吸着パッド**：Φ20 / Φ30 / Φ40mm 程度を 3〜4種類（ミスミ・モノタロウ等、1個 500〜1,500円。跡が付きにくいシリコン推奨。**100均の吸盤は不可**）
- **空気用ダイアフラム真空ポンプ**（Amazon 等で 2,500〜4,000円）：
  - **選ぶ条件**：必ず「空気用」「流量 **10〜15 L/min 以上**」「スマホ画面分離用など（`-55〜-75 kPa` 程度出るもの）」を選ぶ。
  - **⚠️ 注意**：`0.8 L/min` 程度の「水・液体用（ウォーターポンプ）」は流量・真空度が足りずテストにならないため買わないこと。
- **DC12V（または24V）電源アダプタ ＋ 接続用チューブ**
- ※あくまで机上 PoC 用。工場本番では必ずエジェクタまたは産業用電動ユニットに置き換える。

#### パターンB：本番と同じ強さ・応答で試す（合計 1.5〜2万円目安・テストベンチ流用可）
- **FA 用 蛇腹吸着パッド** × 3〜4種 ＋ **バネ付きバッファ（パッドホルダ）** × 1個
- **真空エジェクタ単体**（SMC `ZH` シリーズ等のワンタッチ継手内蔵型：2,000〜4,000円）
- **Φ6 ウレタンチューブ** ＋ **ワンタッチ継手**（パッド側の `M5` / `Rc1/8` ネジに合わせる）
- **小型オイルレスコンプレッサー**（1〜1.5万円程度。※給油式は油が混ざるため NG）

### 机上テストの確認手順
1. **密着確認**：各形状の空ボトルの胴体側面（曲面）にパッドを当て、エア漏れせず持ち上がるか確認する。
2. **姿勢保持確認**：持ち上げた状態で横向き・90度回転・軽く振るなどして、ズレや剥がれが起きないか見る。
3. **変形確認**：薄肉の空ボトルが負圧で凹んだり潰れたりしないか確認する（凹む場合はパッド径を小さくする／圧力を調整する）。
