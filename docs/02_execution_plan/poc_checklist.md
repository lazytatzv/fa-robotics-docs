# Task 1 PoC（要素検証）チェックリスト

全体システムを買い揃えて作り込む前に、**失敗リスクの高い要素だけを最小コストで検証する**ためのチェックリストです。

## 1. 最優先 PoC 項目（Step 2）

| # | 検証項目 | 確認方法 | 合格基準の目安 |
| --- | --- | --- | --- |
| 1 | **色付き透明ボトルの Depth 取得** | 実物ボトル（不透明＋色付き透明）を机上に山積みし、RealSense / Orbbec 等で撮影 | 吸着面付近の Depth 欠損が許容範囲内、または RGB 補間で Z 推定できること |
| 2 | **空ボトルへの真空吸着安定性** | 候補の蛇腹パッド＋エジェクタ（またはポンプ）で、各形状の空ボトルを側面吸着して振り回す | 横持ち・90度回転させてもズレず、凹みや変形が起きないこと |
| 3 | **YOLO-pose / seg の認識精度** | 山積み状態のテスト画像（50〜100枚程度）で「口・底」または領域マスクを推論 | 一番上にあり吸着可能なボトルと向きを安定して判定できること |
| 4 | **サイクルタイム（タクト）試算** | 実機（またはレンタル／メーカーデモ機）で 1ピック＆プレースの所要時間を計測 | 工場が求める 1分あたりの本数（BPM）を満たせる見込みがあること |
| 5 | **Ubuntu Linux からの制御検証** | 候補ロボットの Python SDK / ROS 2 ドライバを Ubuntu PC から繋いで移動＋I/O テスト | 座標移動と DO（吸着）・DI（真空スイッチ）の読み書きが遅延なく動くこと |
