# 案件受注前（着工前）にやっておくべき実践勉強メニュー

実際に案件を受注・実機購入するまでの期間に、ソフト系チームが**最短で「ロボット・FAの勘所」を身につけるための 4週間ハンズオン・メニュー**です。座学だけで終わらせず、手を動かして物理のクセを体験するのがポイントです。

---

## Week 1：全体地図と FA 部品の解像度を上げる
- [ ] **このリポジトリのハンドブックを通読する**
  - [`00_essential_curriculum.md`](./00_essential_curriculum.md) と第1〜5章を読み、チーム内で用語（TF・MoveJ/L・NPN/PNP・エジェクタ・安全回路）を揃える。
- [ ] **FA カタログ・実物を見る**
  - ミスミ、SMC（真空エジェクタ・吸着パッド）、キーエンス/オムロン（透明体用光電センサ）の無料技術資料や選定ガイドを眺めて部品のイメージを掴む。
  - 可能ならロボットメーカーや FA 機器のショールームへ足を運び、実機のサイズ感や動きを見る。

## Week 2〜3：RGB-D カメラ＋空ボトルだけで「目と座標変換」を作る（超重要）
ロボット実機がなくても、**RGB-D カメラ（3〜5万円）と空ボトル数本**があれば最大の難所を先行検証できます。
- [ ] **Docker ＋ Ubuntu 環境構築**：手元の PC に Ubuntu LTS ＋ Docker Compose ＋ NVIDIA GPU 環境を作る。
- [ ] **CVAT ＋ YOLO-pose / seg**：机に置いたボトルを 50〜100 枚撮影し、CVAT で「口・底」のラベル付け → YOLO で傾き・向きを推論させる。
- [ ] **擬似 Hand-Eye キャリブレーション**：机上の ArUco マーカを「擬似ロボットの原点」と見立て、カメラ座標 `(Xc, Yc, Zc)` をマーカ座標 `(Xw, Yw, Zw)` へ $4\times4$ 行列で変換するコードを書く。
  - **ここで得られる体験**：色付き透明ボトルでの Depth 欠損、照明の反射、キャリブレーション誤差を事前に体感できる。

## Week 3〜4：無料シミュレータで「6軸アームの動きと特異点」を体験する
- [ ] **メーカー無料シミュレータ / RViz2 を動かす**
  - 協働ロボットメーカーの無料 PC シミュレータ（または ROS 2 ＋ RViz2）を動かし、`MoveJ` と `MoveL` の違い、リーチ限界、特異点エラーを体験する。
- [ ] **Week 2 の座標をシミュレータに送る**：YOLO が出したボトル座標へ、仮想アームの手先（TCP）をアプローチさせる一連のフローを繋ぐ。

## 余裕があれば（＋1〜2万円）：机上 24V 電気・空圧ミニ実験
- [ ] DC24V スイッチング電源 ＋ 透明体用光電センサ 1個 ＋ 非常停止ボタン（b接点）＋ テスターを机上で繋ぎ、**「24V をテスターで測りながら ON/OFF・NPN/PNP・断線時安全停止」**を実際に触って理解する。
