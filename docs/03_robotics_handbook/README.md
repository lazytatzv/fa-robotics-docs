## ソフトウェア開発との主なギャップ（最初に押さえるべき5点）

| トピック | ソフトウェア開発の常識 | ロボット・FAの現実 |
| --- | --- | --- |
| **環境と入力** | 決定論的・型やAPIで保証される | ワーク公差・滑り・たわみ・照明変化など物理の不確実性がある |
| **座標と位置** | 数値指定すればその通り動く | Base / TCP / Camera / Work の座標系（TF）とキャリブレーションが必須 |
| **動き方** | 始点から終点へ一直線に移動するイメージ | 関節補間（PTP）と直線補間（LIN）、特異点・関節リミット・干渉を考慮する |
| **安全・停止** | 例外処理やソフト側の停止ロジックで制御 | **安全回路（ハードウェア側：STO/非常停止・安全柵）**で確実に止める |
| **エラー復旧** | `try-catch` やプロセス再起動で復帰 | 物理状態を保ったまま人間が安全に復旧し、原点復帰・再開できる状態遷移が必要 |
