# ロボット素人がこのFA案件をやり切るための必須知識・完全チェックリスト

ソフトウェア開発が得意なチームが、**「6軸協働ロボット ＋ 真空吸引 ＋ RGB-D/YOLO ＋ 工場導入」** を安全かつ確実に成功させるために、**絶対に身につけておくべき必須知識の全項目**です。

---

## 1. 安全・法規（最優先：これを知らずに実機を動かさない）
- [ ] **協働ロボットの正しい理解**：協働ロボット＝安全柵不要ではなく、リスクアセスメントの結果として安全な速度・力・先端形状に抑える必要がある（[`03_safety_and_recovery.md`](./03_safety_and_recovery.md)）
- [ ] **ハード安全回路とソフト停止の違い**：非常停止・安全柵・エリアスキャナは PC ではなく**コントローラの安全入力（STO / Safety I/O）**へ直結する
- [ ] **リスクアセスメントの基本**：挟まれ・衝突・ワーク落下/飛散・非常停止時の挙動を洗い出す

## 2. ロボット機構・ハードウェアの基礎
- [ ] **6軸の関節構造と可動範囲**：J1〜J6 の役割と各軸の回転リミット
- [ ] **可搬質量とモーメント**：持ち上げられる重さは「手首からの距離（重心位置）」で減る
- [ ] **実効リーチと手首干渉**：横向きにボトルを掴む姿勢をとると、真上から掴むよりリーチが短くなり壁に当たりやすい
- [ ] **繰返し位置決め精度 vs 絶対精度**：ロボットは「同じ場所に戻る」のは超得意だが、「数値座標 `(X,Y,Z)` に絶対正確に行く」にはキャリブレーションが必須（[`04_hardware_and_pneumatics.md`](./04_hardware_and_pneumatics.md)）

## 3. 座標系（TF）とキャリブレーション
- [ ] **5つの座標系の関係**：Base / Flange / TCP / Camera / Work（[`01_coordinates_and_tf.md`](./01_coordinates_and_tf.md)）
- [ ] **TCP（ツール先端点）の設定**：吸着パッド先端を TCP 登録する意味
- [ ] **姿勢表現の落とし穴**：オイラー角の回転順序（XYZ / ZYX）・単位（deg / rad）のメーカー差、クォータニオンの扱い
- [ ] **Hand-Eye キャリブレーション**：カメラのピクセル＋Depth `(u, v, z)` をロボット Base 座標 `(X, Y, Z)` へ変換する行列の求め方と再キャリブレーション運用

## 4. 運動学と軌道計画
- [ ] **FK（順運動学）と IK（逆運動学）**：IK には複数解（肘の上下等）や解けない姿勢がある（[`02_kinematics_and_motion.md`](./02_kinematics_and_motion.md)）
- [ ] **MoveJ（PTP）と MoveL（直線補間）の使い分け**：移動は `MoveJ`、アプローチと引き抜きだけ短い `MoveL`
- [ ] **特異点（Singularity）の回避**：手首が伸び切る/一直線になる位置に作業エリアを置かない
- [ ] **安全なピック＆プレース軌道**：待機 → 上空 → まっすぐ降下 → 吸着 → まっすぐ上昇 → コンベア上空 → 降ろす

## 5. エンドエフェクタ・真空吸引（空圧）
- [ ] **真空発生方式**：工場エアを使う「真空エジェクタ」と、エア不要な「電動真空ポンプ」の違い（[`04_hardware_and_pneumatics.md`](./04_hardware_and_pneumatics.md)）
- [ ] **吸着パッドとバネバッファ**：曲面対応（蛇腹型）パッドの選定と、Z方向の誤差・衝撃を吸収するスプリングバッファ
- [ ] **吸着確認と破壊ブロー**：真空圧力スイッチ（DI）による把持判定と、置く瞬間に微少正圧を出して素早く離す「破壊ブロー」

## 6. ビジョン・AI（実世界認識）
- [ ] **2D vs 3D（Depth）の特性**：色付き透明ボトルでの Depth 欠損リスクと、RGB（YOLO）＋Depth の補間手法（[`vision_and_ai.md`](../04_architecture/vision_and_ai.md)）
- [ ] **傾きと向きの認識**：水平バウンディングボックスではなく **YOLO-pose（口・底の2点）** や **YOLO-seg / OBB** を使う
- [ ] **照明・環境変動対策**：工場の外光・影・照明のチラツキ対策と、グローバルシャッターの必要性

## 7. 電気・24V I/O・ノイズ対策
- [ ] **電源と降圧**：AC100/200V から FA用スイッチング電源で **DC24V** を作る（[`power_and_wiring.md`](../04_architecture/power_and_wiring.md)）
- [ ] **DI/DO と NPN（シンク）/ PNP（ソース）**：日本のFA機器（NPN主流）と海外製ロボット（PNP主流）で極性が合わず信号が読めないトラブルの回避（[`05_fa_io_and_plc.md`](./05_fa_io_and_plc.md)）
- [ ] **電気ノイズ（サージ）対策**：真空電磁弁の逆起電力で USB カメラや PC が落ちるのを防ぐサージ保護・分離配線

## 8. システム制御・異常復旧・現場運用
- [ ] **ステートマシン設計**：初期化・自動運転・一時停止・異常停止・安全退避（真上に逃げてから原点復帰）の状態遷移（[`03_safety_and_recovery.md`](./03_safety_and_recovery.md)）
- [ ] **工場PC・実行環境**：Ubuntu LTS ＋ Docker Compose ＋ 復電自動起動 ＋ 予備機体制（[`pc_selection.md`](../04_architecture/pc_selection.md)）
- [ ] **現場操作と保守**：作業員にコマンドを触らせない設計（物理ボタン＋パトランプ）、エラー時画像の自動保存、吸着パッド等の消耗品交換運用（[`connectivity_and_maintenance.md`](../05_operations/connectivity_and_maintenance.md)）
