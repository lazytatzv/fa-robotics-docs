# 05. 電気 I/O・FA通信（NPN / PNP の罠）

ソフトウェアエンジニアが実機配線で一番つまずきやすい **DC24V のデジタル I/O（DI/DO）** と **FA特有の極性（NPN / PNP）** の基礎です。

## 1. なぜ PC の GPIO（3.3V / 5V）ではなく DC24V なのか
- 工場はモーターや電磁弁による電気ノイズが大きく、配線も長くなる（数m〜十数m）。
- **DC24V** を使うことでノイズ耐性を確保するのが FA の世界標準。制御PCから直接センサや電磁弁を駆動しようとせず、**ロボットコントローラの 24V DI/DO 端子**を使う。

## 2. 【超重要】NPN（シンク）と PNP（ソース）の違い
センサやロボットの仕様書に必ず出てくる言葉で、**日本のFA機器（キーエンス・オムロン等）は NPN が多く、海外製ロボット（欧州・中国系）は PNP が標準** のことが多いため、ここを間違えると信号が一切読めません。

| 方式 | 特徴（イメージ） | 主な地域・メーカー |
| --- | --- | --- |
| **PNP（ソース出力）** | 信号 ON のとき **+24V** が出力される（海外標準） | 欧州系・多くの中国系協働ロボット |
| **NPN（シンク出力）** | 信号 ON のとき **0V（GND）** に引き込む（日本標準） | 日本の PLC・日本メーカー製センサの多く |

- **対策**：
  - ロボットコントローラが PNP/NPN どちら対応（または配線で切り替え可能）かを事前確認する。
  - センサや電磁弁を買うときは**ロボットの極性に合わせる**（合わなければリレーを1個挟んで変換する）。

## 3. 電磁弁（誘導負荷）とサージ保護
- 真空吸引の電磁弁は内部にコイルが入っているため、OFF にした瞬間に高電圧の逆起電力（サージ）が発生する。
- **対策**：必ず**サージ保護（ダイオード・バリスタ）内蔵の電磁弁**を選び、ロボットの DO 出力や周辺 USB カメラの破損・フリーズを防ぐ。
